ในการเปิดเซฟเวอร์ api รัน python run.py ใช้ terminal คนละตัวกับ mqtt_s
หน้าเว็บ api ของฉัน
- http://localhost:8000/docs (local)
- เพื่อนเข้าไม่ได้เพราะ Windows Firewall บล็อก port 8000 ครับ ต้องเปิด port ก่อน
รันคำสั่งนี้ใน PowerShell แบบ Run as Administrator:
powershellnetsh advfirewall firewall add rule name="Fleet API Port 8000" dir=in action=allow protocol=TCP localport=8000
แล้วรัน server ใหม่โดยเปลี่ยน host ด้วย:
powershell# run.py แก้ host จาก 127.0.0.1 เป็น 0.0.0.0
uvicorn.run(
    "app.main:app",
    host="0.0.0.0",   # ← แก้ตรงนี้
    port=8000,
    reload=False
)
