-สร้างตารางที่เก็บข้อมูลใหม่คือ device_id และ vehicle_id และ date_update_latest(วันที่ที่อัพเดตล่าสุด) ชื่อตาราง update_status โดย primaly key คือ vehicle_id (ถ้าคิดว่าแบบไหนดีกว่าก็เอาทั้งสอแงเลยหรือไม่ก็ 1 ) ✓
-สร้าง api ดึงข้อมูล vehicle_id และ device_id มาอัพเดตในตารางใหม่ ✓
-แก้โครงสร้างโค้ดใหม่ เนื่องจาก vehicle_id ต้องดึงมาจาก odoo โดยทำ api http method  
workflow ใหม่ ✖
-ดึงข้อมูลจากบอร์ด/แล้วก็ vehicle จากodoo แล้วเปลี่ยนจากการดึงข้อมูลจากตาราง telemetry_raw ทั้งหมด และ (vehicle_id) จาก trips_log เป็น telemetry_raw ทั้งหมด และ (vehicle_id) จาก update_status แทน ✖
-โค้ดคำนวณคะแนนจาก telemetry raw จากที่ดึง vehicle จากที่เก่าให้ย้ายมาที่ update_status เลยถ้าจำเป็นนะ  ✖
